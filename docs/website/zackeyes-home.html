Native hooks. Silent failure. Zero drama.

The bridge speaks through Unix sockets, keeps agent hooks quiet when the app is closed, and leaves your terminal workflow intact. 

$ claude code
hook SessionStart → /tmp/zackeyes.sock
hook PreToolUse → task visible in notch
ask PermissionRequest → approve from panel
hook Stop → notify when complete

$ codex
jsonl task_started → live fallback
jsonl task_complete → done
