# v0.10.1 preparation — SSH setup guidance

Status: local development and verification only. Publication requires the user's explicit confirmation. No version bump, release upload, version tag, website publication or PR merge is part of this preparation.

## Scope

Settings → Remote Hosts starts with three steps: install the helper on the remote account, verify SSH from this Mac, then add the named SSH host. The installation command is selectable and has a copy button with feedback, alongside version-matched helper downloads and a setup guide. The host form has persistent labels and SSH configuration guidance. Failed connections link to troubleshooting. Existing host limits, transport, reconnect behavior and read-only boundaries are unchanged; recency/liveness limitations remain visible.

`RemoteSetupGuide` pins both command and download link to the client version. Missing or malformed development versions offer the general release page without inventing a command. Local Info.plist remains 0.10.0, so local testing uses the already published v0.10.0 helper packages. Upon approved v0.10.1 publication, the existing release gate must build/verify/upload all four matching helper packages before publishing the new client.
