# ZackEyes Website

Public website prototype for ZackEyes, a macOS notch command center for Claude Code and Codex CLI.

## Preview

Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Structure

- `index.html` - current static landing page prototype.
- `docs/website-design-plan.md` - design direction, page structure, and open decisions.

## Design Direction

The current direction is immersive 3D for the hero, kinetic typography for scroll narrative, and restrained glassmorphism for product UI surfaces.
